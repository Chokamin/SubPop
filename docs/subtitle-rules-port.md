# SubPop 字幕整理规则迁移

2026-09-12，按用户要求只读检查「奇奇字幕」（VinciSub），移植其已落地的字幕呈现规则。参考工作树 HEAD：`3f448f0e0d4b5fd7af63c71490c440ed76190742`。源文件为 `vincisub/subtitles.py`、`text_units.py` 及 `worker.py` 的生成整理入口。研究记录为该项目的 `docs/subtitle-rhythm-study.md` 和 `docs/expanded-subtitle-study.md`。

源项目记录的研究范围为影视飓风、壹加壹共 25 支影片、19,994 条人工字幕的完整统计，以及短片段画面/声学抽查；不是全片人工听校，不是模型权重训练。SubPop 没有读取或改动奇奇字幕的用户词库、模型、安装或 Resolve 宿主代码。

## 已迁入

| 规则 | SubPop 实现 |

| 数值、单位和技术标识保护 | `probes/text_units.py`，保留 3.5%、1/30、2,000、USB-C、C++、v1.2 等内部符号 |

| 瞬时时间词有限恢复 | 引用规则按邻词实测时间合并；不可靠块保留 SubPop 原断句，记录 `reviewWarnings`，界面提示校对数量 |

保留 SubPop 的有理数帧量化和重叠解决、项目身份/时间校验、已有字幕冲突保护、显式整项目输入及 Title 拖回，不移植 Resolve 落轨方式。原始 ASR 结果始终保留；不会自动改写历史已落轨字幕。

## 与参考项目的必要适配

参考规则对远距离零时长词严格拒绝；当前 22 分钟实测包含此类数据。为了不让整项任务再次失败，SubPop 对这些块保留此前可用的句级时间范围，清理标点并明确提示需要校对。它不是重新对齐，也不声称这些时间精准。普通块使用完整词边界、长度和停顿规则。

原参考项目有每句字数设置、参考脚本重新对齐和手动优化窗口；本轮迁移的是首次生成的自动整理流程，SubPop 使用默认 20 字宽度，尚未增加独立字数设置或参考脚本功能。
