# SubPop 日常 MVP

## 验收目标

2026-09-12 用户将目标从接入验证改为日常可用的 MVP，并确认主要处理 **30 分钟内口播／教程，有剪切和背景音乐**。固定全项目识别；Title 优先，拖入后拆开逐句编辑；在同一个 FCP 插件面板完成模型选择、识别、校对和拖出。

## 明确不包含的高级能力

- 选区模式（用户决定延期）、多机位、复合片段、变速、J/L 分离音频、音频效果、对白音量关键帧、多通道映射。
- FCP 实时 Solo／角色监听混音；当前根据 XML 中的音频角色和启用状态处理。
- 自动改写已有字幕、FCP 与插件双向实时同步、说话人区分、词库、参考稿、翻译。
- GPU／MPS 加速、下载／卸载模型的完整图形管理、签名公证的跨机器安装包。

这些是下一阶段能力，不再阻塞用户确认的普通口播剪切场景；若实际日常素材普遍包含其中某项，应据真实项目扩展验收范围，不能靠忽略未知结构来宣称支持。

## 实际操作

1. 在 FCP 打开目标项目，从浏览器将该项目拖入 SubPop。
2. 选模型及音频范围。背景音乐须分配“音乐”角色；若它与对白已经混在同一个源音轨中，角色过滤无法分离。
3. 开始识别，可取消。修改时间线之后重新拖入；插件不能自动判断同 UID、同总时长内的所有剪辑变化。
4. 校对文字、选择字体字号，再拖到原项目起点上方；使用 FCP“将片段项分开”获得独立 Title。

识别期间不调用 FCP“共享／导出”，音频不上传。模型下载仅从官方仓库接收权重；识别强制离线。
