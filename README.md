# SubPop

**让字幕跟上你的表达。**

为 Final Cut Pro 制作的本机中文字幕插件。<br>
拖入项目，识别整段音频，再把可编辑字幕拖回时间线。

> **当前版本：0.1.0.32**。已作为正式 Release 发布，安装包已完成 Developer ID 签名与 Apple 公证，并通过 Gatekeeper 安装检查。支持范围和已知限制见下文。

## 字幕制作，留在剪辑流程里

- **直接处理 FCP 项目**：识别整个项目的音频，支持普通剪切；无需手动导出音频。
- **本机识别**：模型下载后离线运行，识别过程不上传视频或音频。
- **四种模型可选**：在面板内下载、切换和管理模型，支持下载进度、续传与文件校验。
- **自动整理字幕**：自然断句，去除句子标点，保留小数、单位和技术标识；词库帮助保护专名。
- **回到时间线编辑**：输出 FCP Title 字幕，可逐句修改文字、位置和样式。

不限制视频类型，也不设单次项目的固定时长上限。实际处理速度取决于模型、视频长度和设备性能。

Build 32 减少拖回字幕时的同步日志写入、界面刷新和播放头重复处理。已通过 5000 条字幕的插件端回归；FCP 实际接收大量 Title 时的卡顿改善幅度尚未验证。

## 开始使用

1. **打开插件**：安装后先打开「应用程序」中的 SubPop，再从 Final Cut Pro 的「窗口 → 扩展」菜单打开 SubPop。首次使用时，允许访问默认任务文件夹。
2. **准备模型**：点击面板顶部的「模型」，下载一个识别模型。
3. **拖入项目**：把 FCP 浏览器中的项目拖入 SubPop，选择模型与音频范围，点击「开始识别」。修改时间线后，需要重新拖入项目。
4. **拖回字幕**：识别完成后，把醒目的「拖回字幕到 Final Cut Pro」卡片拖到对应项目时间线的起点、视频上方。对齐项目起点，不是当前播放头位置。
5. **逐句编辑**：选中拖回的字幕包装片段，在 FCP 中选择「片段 → 将片段项分开」，即可编辑各条 Title 的文字和样式。

识别结果仍需校对，尤其是人名、方言、噪声较大或多人同时说话的片段。面板中的字幕预览和样式选项也可以按需展开。

## 模型选择

| 模型 | 本机运行方式 | 模型下载大小（约） |
| --- | --- | --- |
| Qwen3-ASR 0.6B | CPU | 1.88 GB |
| Qwen3-ASR 1.7B | CPU | 4.70 GB |
| Whisper Large v3 Turbo | MLX | 1.61 GB |
| SenseVoiceSmall | CPU | 0.94 GB |

两个 Qwen 模型还需要约 **1.84 GB** 的共用时间对齐模型，首次下载会自动补齐。切换这两个模型时无需重复下载共用文件。

默认优先使用第三方 **HF-Mirror 国内镜像**，失败后尝试 Hugging Face 官方源，也可选择仅使用官方源。下载使用固定版本和 SHA-256 校验；不同网络的速度和可访问性可能不同。

词库可用于专名保护。不同引擎对提示词的支持不同：SenseVoice 的词库参与字幕整理，不改变模型识别过程。

## 使用前了解这些限制

- 暂不支持变速、复合片段、多机位、J/L 音频，以及部分音频效果、音量关键帧和多通道映射。遇到不支持的结构会提示失败。
- 「仅对白」按 FCP 音频角色过滤音乐。如果背景音乐已经混在对白源文件中，无法靠角色过滤将其分离。
- 输出为 **Title 片段**，不是 FCP 原生的 Captions 字幕轨。
- 当前版本尚未在另一台干净 Mac 上完成安装到 FCP 落轨的完整验收。

## 数据与更新

模型、词库和任务数据保存在本机：

```text
~/Library/Application Support/SubPop
```

检查更新和下载模型需要联网；音频识别在本机完成。面板顶部「检查更新」查询 GitHub 的正式 Release，提供下载页，不会自动安装。公开测试版请到 Releases 页面手动查看。

曾安装旧开发版 `SubPop Probe.app` 的测试者，应先退出并移走旧应用，避免重复注册扩展。旧开发目录中的模型与任务不会自动迁移。

### Tap5a 自适应底框（开发版 Build 37）

识别完成后，在主操作卡片下方的「字幕样式」选择「Tap5a · 自适应底框」。首次选择已安装的 `Tap5a Autosize Text Background.moti`，之后会记住位置。切换复用当前识别结果及 SubPop 内的校对文字，无需重新识别；可随时切回基础字幕。

选择 Tap5a 后，点击「整批样式」在「文字」页调整本机字体、字形／粗细、字号、字距、额外行间距和文字颜色；在「底框与留白」页统一调整底框颜色、不透明度、圆角、四侧留白，以及边框颜色、宽度、不透明度和位置。点击「应用到全部字幕」保留当前文字与时间；「保存预设并应用」保存一份“我的预设”，以后可直接载入。「文字效果」页可分别启用文字外框、光晕与投影：外框支持颜色、宽度、不透明度；光晕沿用 Tap5a 暖黄色，支持不透明度、半径、模糊；投影支持颜色、不透明度、模糊、距离与角度。当前文字与底框样式也会随 SubPop 草稿恢复。字号支持 1–1000 和小数，数值框在结束编辑时校验范围。行间距仅影响多行字幕；字距使用点，FCP 检查器会按字号换算为百分比。

「文字」页的 X／Y 偏移按项目像素调整整批字幕的位置，文字与底框一起移动。X 正值向右、Y 正值向上，0／0 保持默认位置；位置会随预设与草稿保存。应用后重新导入即可，无需重新识别；FCP 时间线上已有的字幕需要替换。

样式面板左侧显示当前字幕对应的源视频帧，可切换上一句、下一句；调整参数时，文字与底框示意即时更新。普通主时间线剪切支持自动取帧，变速、复合片段和复杂嵌套暂不支持；读取失败时可选择视频截图作为背景。预览不包含 FCP 调色、特效与 Motion 渲染，最终底框效果以 FCP 为准。预览不会修改 FCP 时间线。「安全框」开关显示 90% 动作安全区和 80% 标题安全区，参考线不会导出。点击「全屏预览」放大当前视频帧及字幕，点击右上角「退出全屏」返回；当前是静帧样式预览，不是视频播放。

Tap5a 使用两步导入，避开大量模板字幕直接拖回失败的问题：

1. 点击「导入字幕到 Final Cut Pro」。如果 FCP 询问资源库，选择原项目所在资源库。
2. 在 FCP 浏览器的「SubPop 字幕」事件中，找到「项目名 · Tap5a 字幕」，将整个片段拖到原项目时间线起点上方。再选择「片段 → 将片段项分开」，即可逐句编辑文字和底框。

发送导入请求不代表 FCP 已完成导入，请在浏览器中确认结果。再次点击会重新导入；不需要重新识别。基础字幕仍支持从 SubPop 直接拖回时间线。

需要自行安装 [Tap5a Autosize Text Background](https://github.com/tap5a/free-final-cut-pro-x-plugins)，SubPop 不附带或修改第三方模板。此功能生成新的字幕片段，不会替换已经拖入 FCP 的旧字幕，也不会读取你后来在 FCP 中做的文字修改。
