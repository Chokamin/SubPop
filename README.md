## 用 SubPop 做什么

- **从项目开始**：直接接收 FCP 浏览器中的完整项目，省去手动导出音频。
- **在本机识别**：四种模型可选，下载后离线运行，识别时不上传音频或视频。
- **整理中文表达**：自动断句、去除句子标点，保留数值、单位与技术标识；词库帮助统一专名写法。
- **简繁切换**：识别后选择保持原文、简体或繁体，时间不变，无需重新识别。
- **参考脚本校对**：粘贴或导入文案，在可靠匹配时辅助纠错和统一写法，保留现场表达与脚本的差异。
- **整批调整样式**：搭配 Tap5a 自适应底框，统一设置文字、底框、位置与效果，边调边预览。
- **回到 FCP 编辑**：生成可逐句修改的 Title 字幕片段，继续完成剪辑。

## 豆包云端识别

本机模型之外，1.1.0 增加了可选的豆包录音文件识别 2.0。只需配置语音服务 API Key。

1. 在[火山引擎豆包语音控制台](https://console.volcengine.com/speech/new/setting/apikeys)开通「录音文件识别 2.0」，创建语音服务 API Key。此处不是方舟聊天模型密钥，也不需要开通极速版。
2. SubPop「模型」→「豆包录音文件识别 2.0」→「配置云端识别」，填写 API Key 并保存。密钥保存在 macOS 钥匙串；保存不会上传音频或验证服务额度。
3. 选择豆包模型，拖入项目，在确认音频上传和计费后开始识别。

只需语音 API Key，不需要 APP ID、Access Token 或 TOS 存储桶。SubPop 将音频分成不超过 1 分钟的小段，直接提交给标准版 2.0，再查询识别结果。视频画面、FCP 项目文件和词库不上传；音频不会传到 SubPop 开发者的服务器，识别费用由你的火山引擎账户结算。

识别提交不自动重试；取消、超时或断网后，已经提交的部分仍可能计费。返回结果沿用 SubPop 的本机词库规范化、断句和字幕样式流程。此前已保存的 API Key 会继续使用，无需重填。

已用真实服务验证标准版 2.0 的 API Key 直接提交音频、查询文字和逐字时间戳。短音频测试不代表所有素材的识别质量或长项目稳定性。[官方接口说明](https://www.volcengine.com/docs/6561/1354868?lang=zh)

## 第一次使用

1. **安装 SubPop**：下载上方 `.pkg` 文件，按安装向导完成安装。Releases 中的 `Source code` 是源码，不是安装程序。
2. **打开扩展**：首次安装后先打开「应用程序」中的 SubPop 一次，让 FCP 注册扩展；之后从 FCP「窗口 → 扩展 → SubPop」打开面板。SubPop 会自动启动并连接本机服务，无需手动选择任务文件夹。
3. **拖入项目**：在 FCP 中打开要处理的项目，再把浏览器里的该项目拖入 SubPop。即使还没有下载模型，也能正常导入并显示项目名称与时长。
4. **开始识别**：确认模型与音频范围，点击「生成字幕」。所选本机模型尚未下载时，点击弹窗中的「下载并开始识别」，SubPop 会显示下载进度，校验完成后自动识别当前项目；也可提前在顶部「模型」中下载。
5. **校对结果**：展开字幕预览，检查文字和断句，默认使用无底框的普通字幕，也可切换为 FCP 原生底框或 Tap5a 样式送回 FCP。

SubPop 使用拖入时的项目快照。修改过时间线后，请重新拖入项目；即使总时长没变，SubPop 也无法仅凭项目名称和时长发现片段、音轨或已有字幕的变化。一次识别完成后，若点击「清空本次字幕」或要重新识别，项目名称和设置仍会保留，但必须重新拖入该项目，防止按旧快照识别或遗漏重复字幕。清空不会删除 FCP 时间线中已有的字幕。当前处理整个项目，不是浏览器里的单个素材或时间线选区。

一个项目识别完成后，可以直接打开并拖入另一个项目，无需先清空。若在识别仍进行时切换 FCP 时间线，SubPop 会取消旧任务；随后可直接拖入新的项目。若直接拖入有效的新项目，也会先取消旧任务再接收新项目。已经提交的豆包云端任务仍可能计费。无关或无效的拖入不会取消旧任务。

### 项目音频无法直接读取时（1.3.4 起）

正常情况下仍直接拖入 FCP 项目并点击「生成字幕」，不需要导出音频。如果提示无法完成识别或项目没有可识别音频，可以在 FCP 中**从项目起点到结尾导出整条时间线的音频**，然后把 WAV、AIFF、M4A 或 CAF 文件拖到 SubPop 的项目卡片上；也可以点击错误提示下方的「导入整条时间线音频…」。保留原项目打开和已拖入状态，SubPop 会继续使用该项目的身份、帧率与字幕时间轴，自动开始识别，不需要把音频单独作为新项目拖入。

备用音频必须与项目总时长一致；片段导出会被拒绝，以免字幕错位。它包含 FCP 导出的最终混音，因此「仅对白」角色筛选对这次识别不生效，导出时请在 FCP 中确认需要的音频角色与效果。选豆包模型时仍会先确认上传和计费。时间线改动后，应重新拖入项目，再导出并拖入匹配的新音频。生成字幕后仍按原方式校对、拖回或下载字幕文件。

### 参考脚本（可选）

拖入项目后，点击顶部「词库」旁的「参考脚本」，粘贴文案或导入 TXT / Markdown 文本。脚本按项目保存在本机，最多 20000 字；启用后，生成字幕时会自动参考。

SubPop 以实际识别的语音为准，在上下文匹配时辅助校正同音错字、统一英文名称及等值数字写法，并参考脚本标点断句。脚本中没读出的段落不会补入字幕，临时加话、现场改说、不同的数字和否定表达会保留；匹配不可靠时保留识别结果，仍建议校对。

已有字幕可选择「保存并整理当前字幕」，无需重新识别，保留当前字幕的时间和分句。整理后可「撤销脚本整理」。关闭或清空脚本后，下次生成不再参考。此功能使用本机文本比对，不需要额外模型或 API Key；使用豆包识别时，参考脚本也不会上传。

如果重新识别失败，可用「恢复上次字幕」找回当前项目的已完成结果。恢复历史结果后，重新识别前需要再次拖入项目。

## 将字幕放回时间线

### 普通字幕与 FCP 原生底框：直接拖回

「普通字幕 · 无底框」是默认样式；需要底框时，可选择「FCP 原生 · 自适应底框」。两种都使用 FCP 内置模板。原生底框的背景、圆角和动画可在 FCP 检查器中调整。

1.3.6 起，选择原生底框后，展开预览与样式并点击「预览与样式」，可调整字体、字号、颜色、字距、行间距、底框颜色与不透明度、圆角、宽高调整、位置偏移和动画。输入名称点击「保存预设」，即可保存多套样式；同名保存会更新原预设。载入后点击「应用到全部字幕」，无需重新识别。设为默认后，新识别结果切换到原生底框时会使用该样式；字幕类型仍默认普通无底框。 原生样式面板提供视频帧上的静态字幕预览，可切换前后字幕、选择截图背景及全屏查看。 自动取帧支持主时间线直接视频素材，以及普通片段和空隙容器内嵌套的视频；读取原素材画面，不包含 FCP 中的合成和效果。预览不包含 Motion 动画、Z 轴透视或 FCP 调色特效，最终画面以 FCP 为准。字距使用与 FCP 检查器相同的字号百分比；旧预设的实际字距会保持不变。

要保存已经在 FCP 调整好的原生底框字幕，请重新把完整项目拖入 SubPop，再在「预览与样式」的「读取项目字幕」中选择对应字幕，读取静态参数后命名保存。1.3.8 起也保存 FCP「文本」页的位置 X／Y／Z，与模板发布的 X／Y 位置偏移分别保留。1.3.6 的旧预设未记录文字位置，请重新读取对应字幕并同名保存一次。预设仅保存支持的文字、位置和已发布底框参数，不包含字幕内容、时间或关键帧动画；实际画面以 FCP 渲染为准。调整后请重新拖回字幕或下载 FCPXML，FCP 时间线上已有字幕不会自动改变。

识别完成后，结果区默认显示字幕数量；点击「查看字幕」可展开文字列表进行检查。字体、字号及其他样式统一在字幕类型旁的「预览与样式」中调整。

1.4.6 新增「文字形式」：保持原文、简体或繁体。切换会同步更新字幕列表、画面预览、SRT 和 FCPXML，保留字幕数量和时间，无需重新识别。转换词典随插件提供，在本机运行，不需要额外模型或服务费用。转换前的校对稿会保留，选回「保持原文」即可恢复；手动校对会更新该句的校对稿，关闭重开也会恢复已保存的文字形式。采用标准简繁转换，不替换地区用词；转换结果仍可校对。FCP 时间线上已有字幕不会自动修改，请重新导入或拖回新输出。

1.4.2 起，普通字幕也支持「读取项目字幕」：先将完整项目重新拖入 SubPop，在「普通字幕 · 无底框」的「预览与样式」中选取已调整好的基础标题字幕，再命名保存预设或应用到当前全部字幕。列表显示字幕实际文字和项目时间，普通字幕与原生底框分别筛选。普通字幕的文本位置 X／Y／Z 与画面偏移分别保存；旧预设保持原有位置。读取使用最近一次拖入的项目快照，FCP 中后来修改的样式需重新拖入后读取。关键帧、混合文字样式，以及当前未支持的缩放、旋转等设置不会被静默转成不完整预设；第三方标题模板不在普通字幕读取列表中。

把 SubPop 的「拖回字幕到 Final Cut Pro」卡片拖到**原项目时间线起点、视频上方**。字幕以项目起点对齐，不以当前播放头位置对齐。

需要逐句编辑时，选中整段字幕包装片段，执行 FCP「片段 → 将片段项分开」，即可分别调整每条字幕。

### Tap5a 自适应底框：先导入，再拖回

在「字幕样式」中选择「Tap5a · 自适应底框」。首次使用时，可点击「下载并安装 Tap5a」，也可点击「选择已安装的模板…」选择已有的 `Tap5a Autosize Text Background.moti`。完成后会记住位置。

1. 在 SubPop 中点击「导入字幕到 Final Cut Pro」。如 FCP 询问资源库，选择原项目所在资源库。
2. 等待 FCP 导入完成，浏览器会显示本次新建的编号事件（例如「SubPop 字幕 001」），其中只有对应的「项目名 · Tap5a 字幕 001」字幕片段。每次导入使用新序号并保留旧版，插件也会提示本次的完整名称。将新片段拖到**原项目时间线起点、视频上方**。

选中导入的字幕片段后，同样可以执行「将片段项分开」来逐句编辑。每次导入会增加编号，减少同名冲突。点击导入只表示已发送请求，请在 FCP 浏览器中确认结果。

切换字幕样式或重新导入无需再次识别。调整样式后会生成一份新字幕，**不会同步修改 FCP 时间线上已有的字幕**；请按需移除旧版，避免重叠。SubPop 也不会读取后来在 FCP 中修改的文字。

识别完成后，结果卡片下方可选择「下载 SRT 文件」或「下载 FCPXML 文件」，自行指定保存位置。SRT 包含当前校对后的文字和逐句时间，不包含底框等视觉样式；FCPXML 包含当前选中的字幕样式和文字，可在 FCP 中作为新的浏览器字幕片段导入，不会替换现有项目。两个文件都只反映 SubPop 当前结果，不会读取你之后在 FCP 时间线上做的修改。

时间线上已有普通字幕、FCP 原生字幕或第三方视觉标题时，SubPop 会在音频处理副本中排除标题；动画、视频滤镜等视觉嵌套不会阻止识别。若标题内包含音频片段或无法判断其音频来源，则会提示暂不支持。原时间线和已有标题不会被修改；生成新字幕后会提示检查与已有文字标题的画面重叠。复合片段内的静音标题也会排除。1.4.6 起新增同步片段和明确选定音源的多机位读取。

## 安装 Tap5a（可选）

当前适配的是 **Tap5a Autosize Text Background**，不是 Multiline Text Background 或其他 Tap5a 模板。模板由 [Tapio Haaja（tap5a）](https://github.com/tap5a/free-final-cut-pro-x-plugins#tap5a-autosize-text-background) 提供。SubPop 从作者源下载安装，保留作者说明，不随安装包重新分发模板。

### 在 SubPop 中安装

1. 识别完成后，选择「Tap5a · 自适应底框」，点击「下载并安装 Tap5a」。
2. 在系统授权窗口中选择当前用户的「影片」文件夹，点击「授权并安装」。
3. 等待下载与安装完成，SubPop 会自动选择模板；如果 FCP 尚未显示新模板，重新打开 FCP。

下载约 **37 KB**，需要连接作者的 GitHub 源；网络不可达时可重试或手动安装。安装前会校验固定版本文件，保留已有模板；同名文件夹不兼容时会提示处理，不会覆盖你的修改。

### 手动安装

已安装的用户可直接选择模板；无法联网或使用其他安装位置时，也可按以下方式安装：

1. 打开作者的 [Tap5a_Autosize_Text_Background.zip 下载页](https://github.com/tap5a/free-final-cut-pro-x-plugins/blob/main/Tap5a_Autosize_Text_Background.zip)，点击「Download raw file」下载并解压。
2. 在 Finder 按 **⌘⇧G**，前往下面的目录。缺少文件夹时创建对应文件夹；已有 Motion Templates / Titles 目录时使用原目录，不要再建一套。

   ```text
   ~/Movies/Motion Templates.localized/Titles.localized/Tap5a/
   ```

3. 将解压后**包含 `.moti` 文件的整个 `Tap5a Autosize Text Background` 文件夹**放进去，保留其中的 `Media`、预览图和模板文件。最终结构应为：

   ```text
   Tap5a/
   └── Tap5a Autosize Text Background/
       ├── Tap5a Autosize Text Background.moti
       ├── Media/
       ├── large.png
       └── small.png
   ```

4. 如果 FCP 已打开，重新打开 FCP。确认标题浏览器的 Tap5a 分类里能看到模板，再回到 SubPop 选择它。

Finder 可能将这些目录显示为「影片」「Motion Templates」或「Titles」，不显示 `.localized` 后缀。SubPop 当前需要模板位于 `Titles.localized` 目录内，不能直接选择「下载」文件夹中的副本。作者的通用安装说明见 [Tap5a 安装指南](https://github.com/tap5a/free-final-cut-pro-x-plugins#installation)。

## 调整样式与预览

普通无底框字幕也可点击「预览与样式」，在对应视频静帧上查看文字，调整字体、字形、字号、颜色、字距、行间距和 X／Y 位置。1.3.12 起，普通字幕支持多套命名预设：填写名称后点击「保存预设」，从「样式预设」载入；同名保存会更新原预设。点击「应用到全部字幕」更新当前输出，无需重新识别；FCP 中已有的字幕需重新替换。设为默认后，之后新识别的普通字幕会使用该样式，也可取消默认或删除预设。普通字幕和原生底框使用独立预设库，预设只保存样式，不保存字幕文字或时间。普通字幕预览不会添加底框或底框边框。普通字幕与原生底框面板均可在「文字效果」页设置外框、投影及光晕；效果随字幕导出，两种字幕的命名预设都会保存这些效果。光晕可设置颜色、不透明度、半径和模糊。

选择 Tap5a 后，点击「预览与样式」，将当前字幕统一为同一套视觉样式。

| 分类 | 可调整内容 |
| --- | --- |
| 文字 | 字体、字形／粗细、字号、颜色、字距、额外行间距 |
| 位置 | X／Y 偏移，文字与底框一起移动 |
| 文字效果 | 外框、光晕、投影及各自的相关参数 |
| 底框与留白 | 颜色、不透明度、圆角、四侧留白、边框 |
| 预设 | 应用到全部字幕，或保存预设供以后载入 |

X 正值向右，Y 正值向上；偏移以项目像素为单位，支持正负值。字号支持 1–1000 和小数。双击参数前的文字标签，可将该项数值恢复默认值。数值支持左右拖动调整，部分 FCP 宿主环境的拖动与 Shift 精调仍需验证。额外行间距仅影响多行字幕。

预览显示当前字幕对应的**源视频静帧**，支持上一句／下一句、90% 动作安全框、80% 标题安全框和全屏预览。参数变化会更新预览；自动取帧失败时，可自行选择视频截图作为背景。安全框不会出现在导出的字幕中。

预览不是视频播放，也不包含 FCP 调色、特效或完整 Motion 渲染；最终效果以 FCP 为准。

## 让词库统一专名写法

在「词库」中添加希望输出的完整写法，并启用词库。例如：

| 词库中的写法 | 可规范的识别结果 | 输出 |
| --- | --- | --- |
| `iPhone 18 Pro` | `iPhone十八pro` | `iPhone 18 Pro` |

词库参与断句保护，并统一匹配词条的大小写、空格和等值数字写法。它不会把不同型号强行替换，也不能保证纠正所有同音词或错听。不同模型对识别提示词的支持不同；SenseVoice 的词库在字幕整理阶段生效。

新增或修改词库后，在下一次识别时生效，不会自动改写已经导入 FCP 的字幕。

## 常见问题

**没有 Tap5a 能用吗？**

可以。基础字幕无需第三方模板；选择自适应底框时，可在 SubPop 内下载并安装 Tap5a。

**为什么 Tap5a 不能像基础字幕一样直接拖回？**

当前版本的大批量模板字幕采用「导入到 FCP 浏览器 → 拖回时间线」两步流程。请按上面的 Tap5a 操作步骤使用。

**更新后，旧字幕会跟着变吗？**

不会。新版本的识别、断句和样式修改作用于新生成的结果，FCP 中已有的字幕需要自行替换或编辑。

**为什么还要校对？**

识别与断句不能保证完全准确，尤其是专名、方言、噪声和多人同时说话的片段。导入前请检查关键内容。

**FCP 扩展菜单里没有 SubPop？**

先打开「应用程序」中的 SubPop，再重新打开 FCP。

**显示「本机未连接」或尚未下载模型？**

扩展会自动启动并连接本机服务；若主界面持续提示连接失败，点击「重新连接本机服务」重试。安装包不含模型，但无需先下载再导入：拖入项目并点击「生成字幕」，按提示确认后即可自动下载并接着识别。

## 当前支持范围

- 支持整项目识别、普通剪切、嵌套复合片段，以及音频片段或整个复合片段的线性变速；可组合内外两层同一音调模式的线性变速。FCP 的「速度斜坡」在关闭「速度转场」时生成的分段线性映射也可处理，包括其极短的起始停顿与超出片段结尾的映射点。变速音频按 `timeMap` 的时间关系重建，保留音调时使用本机音频拉伸，识别用音频可能与 FCP 的最终混音不完全相同。只有画面倒放、对白音频另行正常播放时仍可识别对白。对白本身倒放、明显停帧或开启「速度转场」后的平滑变速会跳过受影响的音频片段，并在结果中标出项目时间段；其他对白继续识别。若因此没有可识别音频，会明确提示。
- 对白片段上的 FCP 内置降噪、语音隔离、EQ、响度、哼声处理，以及压缩器等音频效果插件不会阻止识别。SubPop 使用原媒体音频及受支持的音量调整来识别，不会运行这些效果插件；结果会提示有多少处效果未参与识别。原录音严重依赖降噪才能听清时，识别准确率可能低于 FCP 里听到的处理后声音。前后片段连续、时长不超过两秒的普通 FCP 转场可直接识别；转场附带的标准音频交叉淡入淡出会按原片段硬切处理，并提示核对转场附近字幕。更复杂的转场仍可使用整条时间线导出音频的保底入口。音量关键帧和自定义输出通道重映射仍不支持，遇到这些情况会明确提示。
- 1.4.4 支持 59.94 帧素材的正常帧率适配，以及音频和画面起止不同的普通 J／L 剪辑：按音频自己的起止读取，保留项目中的静音和时间位置。实际媒体容器中的短音轨或延迟音轨会在确认无声的范围补静音；损坏或超出媒体范围的读取仍会报错。分离音频起止与变速同时使用的组合仍需整条时间线导出音频作为备用来源。
- 1.4.6 起支持 29.97 帧源格式在 30 帧项目中的已验证速度适配，按实际父级时钟换算音频；新增常规同步片段及多机位明确选中的音频角度，保留裁切、角度切换、角色过滤、整组静音及静态音量。不会混入仅用于画面的机位声音。音频角色组件单独裁剪、区间静音、未知帧率适配等复杂设置仍需备用导出音频；缺失角度选择时不会猜测音源。已使用 FCP 独立测试项目核对声音时间，用户反馈原项目尚未取得。
- 1.4.8 起支持常规多声道及多音轨媒体，按项目明确启用的音频组件选择通道、过滤音乐角色并应用各组件的静态音量。缺少可选声道元数据时检查实际媒体，不再直接拒绝；媒体布局与项目声明冲突、音源关系不明确或音轨存在备用编码关联时，仍提示使用完整导出音频。已用 FCP 的四声道与双立体声音轨测试项目核对通道顺序和静音选择；用户反馈原项目尚未取得。同时修复了导入备用音频时文件校验的栈溢出崩溃；这一错误会使 FCP 提示「重新打开扩展」。
- 1.4.10 修复了 FCP HDR／SDR 颜色适配及其他内置画面调整被误判为音频设置的问题；这些画面调整不会阻止受支持片段的直接识别。同步修复了音频采样率转换时偶发的尾部数据差异，保留默认下混、音源选择和原有完整性检查。画面效果不会参与音频识别，原项目也不会被修改。
- 「仅对白」按 FCP 音频角色过滤音乐，不能分离已经混进同一源文件的背景音乐。

上述直接读取限制不妨碍使用整条时间线的导出音频作为备用来源；备用来源识别的是导出后的完整混音，仍需确认时长及校对结果。
- 输出为 **Title 标题片段**，不是 FCP 原生的 Captions 字幕轨。
- 当前实测环境为 FCP 12.3，尚未在另一台干净 Mac 上完成安装到落轨的全流程验收。

## 数据、更新与反馈

使用本机模型时，识别在本机完成；检查更新和下载模型时需要联网。开发版选择豆包云端模型并确认后，音频会上传至火山引擎。正式安装版的模型和任务文件保存在：

```text
~/Library/Application Support/SubPop
```

面板中的「检查更新」默认先连接 GitHub，失败后自动尝试镜像。也可以选择「仅 GitHub」或「镜像优先」，并修改镜像地址；默认使用 [GH-Proxy](https://gh-proxy.com/docs/github-accelerator)，版本查询和安装包下载都支持备用通道。公共镜像的可用性取决于网络及服务状态。

从 1.2.1 起支持在线更新：点击「立即更新」，在 SubPop 更新窗口内完成下载、验证、安装和重启，无需另存安装包或打开安装向导。需要管理员权限时由 macOS 提示授权。更新期间暂停接收新任务；已有识别、脚本整理或模型下载完成后才能开始更新。安装前保存字幕草稿并关闭 SubPop 扩展，完成后从 FCP 扩展菜单重新打开即可。正式版 1.2.0 及更早版本仍使用原来的下载安装包方式。更新源只接收公开的版本查询和文件下载请求，不会收到项目、音频、参考脚本或 API Key。各版本的改动和校验文件见 [Releases](https://github.com/Chokamin/SubPop/releases)。

1.4.12 起，点击插件顶部的对话气泡图标「问题反馈」，只需填写一段问题说明；SubPop 版本、Build、macOS 和处理器类型会自动填入使用环境。可选取一张 PNG、JPEG 或 WebP 静态截图（最多 10 MB），在插件中预览。选择截图只保存在当前反馈面板，不会自动上传。

点击继续按钮后，说明和环境会预填到 GitHub 网页；已选截图会先复制到剪贴板，请在网页的「截图」框按 **⌘V**，图片才会上传。内容较长时，先将复制的正文粘贴到「问题说明」，再回到插件点击「复制截图」，在网页截图框粘贴。也可直接把截图拖到网页中。检查内容与图片后，由你确认提交 Issue；插件不会自动提交，也不会附加项目、字幕、音视频、日志或凭证。

也可打开 [反馈页面](https://github.com/Chokamin/SubPop/issues/new/choose)，选择「问题反馈」或「功能建议」。提交需要登录 GitHub 账号，之后可在对应 Issue 查看处理进展和修复版本。反馈和图片会公开显示，请先遮盖个人信息，不要提交 API Key、私人音视频、完整项目或资源库。

仓库公开 SubPop 源码与模型清单；模型权重和 Tap5a 模板不随源码或安装包分发。模型、模板与第三方依赖遵循各自的使用条款。

### 在线更新发布（开发者）

原生构建会获取固定版本、SHA-256 校验的 Sparkle 2.10.0。更新组件仅运行于 SubPop 主程序，FCP 扩展仍保留沙箱。更新源 XML 和安装包均须使用专用 Ed25519 密钥签名，私钥位于本机钥匙串，不进入源码或发行包。Sparkle 许可证随框架分发。

完成 Developer ID 签名、Apple 公证和附票后，为**该安装包内的构建号**生成更新源：

```sh
.venv/bin/python scripts/prepare_update_feed.py dist/SubPop-VERSION-arm64.pkg --build BUILD
```

将生成的 `dist/appcast.xml` 与 PKG、SHA-256 一起上传到同一个 GitHub Release，验证附件后再设为 latest。每次发行均须生成新的已签名更新源；不能修改已签名 XML 或安装包。
