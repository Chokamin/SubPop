# SubPop

**让字幕跟上你的表达。**

为 Final Cut Pro 制作的本机中文字幕插件。<br>
拖入项目，识别整段音频，再把可编辑字幕拖回时间线。

[下载安装包](https://github.com/Chokamin/SubPop/releases) · [使用方法](#开始使用) · [反馈问题](https://github.com/Chokamin/SubPop/issues)

</div>

> **公开测试中**：当前版本为 0.1.0.29。安装包尚未完成 Developer ID 签名和 Apple 公证，macOS 可能阻止安装或启动。签名版发布后会在这里更新说明。

## 字幕制作，留在剪辑流程里

- **直接处理 FCP 项目**：识别整个项目的音频，支持普通剪切；无需手动导出音频。
- **本机识别**：模型下载后离线运行，识别过程不上传视频或音频。
- **四种模型可选**：在面板内下载、切换和管理模型，支持下载进度、续传与文件校验。
- **自动整理字幕**：自然断句，去除句子标点，保留小数、单位和技术标识；词库帮助保护专名。
- **回到时间线编辑**：输出 FCP Title 字幕，可逐句修改文字、位置和样式。

不限制视频类型，也不设单次项目的固定时长上限。实际处理速度取决于模型、视频长度和设备性能。

## 下载与安装

| 项目 | 要求 |
| --- | --- |
| Mac | Apple Silicon（M 系列芯片） |
| 系统 | macOS 15 或更高版本 |
| 剪辑软件 | Final Cut Pro；当前实测版本为 12.3 |
| 安装包 | PKG，约 461 MB；模型另行下载 |

在 [Releases](https://github.com/Chokamin/SubPop/releases) 下载以 `.pkg` 结尾的附件，按安装向导完成安装。GitHub 自动提供的 **Source code** 是源码，不是安装程序。

安装包包含独立运行环境，无需安装 Python 或配置终端命令。

## 开始使用

1. **打开插件**：安装后先打开「应用程序」中的 SubPop，再从 Final Cut Pro 的「窗口 → 扩展」菜单打开 SubPop。首次使用时，允许访问默认任务文件夹。
2. **准备模型**：点击面板顶部的「模型」，下载一个识别模型。
3. **拖入项目**：把 FCP 浏览器中的项目拖入 SubPop，选择模型与音频范围，点击「开始识别」。修改时间线后，需要重新拖入项目。
4. **拖回字幕**：识别完成后，把醒目的「拖回字幕到 Final Cut Pro」卡片拖到对应项目时间线的起点、视频上方。对齐项目起点，不是当前播放头位置。
5. **逐句编辑**：选中拖回的字幕包装片段，在 FCP 中选择「片段 → 将片段项分开」，即可编辑各条 Title 的文字和样式。

识别结果仍需校对，尤其是人名、方言、噪声较大或多人同时说话的片段。面板中的字幕预览和样式选项也可以按需展开。

## 模型选择

| 模型 | 本机运行方式 | 模型下载大小（约） |
| --- | --- | --- |
| Qwen3-ASR 0.6B | CPU | 1.88 GB |
| Qwen3-ASR 1.7B | CPU | 4.70 GB |
| Whisper Large v3 Turbo | MLX | 1.61 GB |
| SenseVoiceSmall | CPU | 0.94 GB |

两个 Qwen 模型还需要约 **1.84 GB** 的共用时间对齐模型，首次下载会自动补齐。切换这两个模型时无需重复下载共用文件。

默认优先使用第三方 **HF-Mirror 国内镜像**，失败后尝试 Hugging Face 官方源，也可选择仅使用官方源。下载使用固定版本和 SHA-256 校验；不同网络的速度和可访问性可能不同。

词库可用于专名保护。不同引擎对提示词的支持不同：SenseVoice 的词库参与字幕整理，不改变模型识别过程。

## 使用前了解这些限制

- 暂不支持变速、复合片段、多机位、J/L 音频，以及部分音频效果、音量关键帧和多通道映射。遇到不支持的结构会提示失败。
- 「仅对白」按 FCP 音频角色过滤音乐。如果背景音乐已经混在对白源文件中，无法靠角色过滤将其分离。
- 输出为 **Title 片段**，不是 FCP 原生的 Captions 字幕轨。
- 当前测试版尚未在另一台干净 Mac 上完成安装到 FCP 落轨的完整验收。

## 数据与更新

模型、词库和任务数据保存在本机：

```text
~/Library/Application Support/SubPop
```

检查更新和下载模型需要联网；音频识别在本机完成。面板顶部「检查更新」查询 GitHub 的正式 Release，提供下载页，不会自动安装。公开测试版请到 Releases 页面手动查看。

曾安装旧开发版 `SubPop Probe.app` 的测试者，应先退出并移走旧应用，避免重复注册扩展。旧开发目录中的模型与任务不会自动迁移。
